# 🍴 Yummy Foods – Responsive Restaurant Website

A responsive and visually appealing restaurant website developed using **HTML5 and CSS3**.  
The project showcases different food categories such as burgers, fries, healthy food, noodles, and desserts through a clean and user-friendly interface.

## 📌 Project Overview

**Yummy Foods** is a frontend web development project designed to demonstrate the fundamentals of creating a structured and responsive restaurant website.

The website includes a navigation menu, welcome section, food category sections, image-based food galleries, and a footer.
The project focuses on:
- Clean webpage structure
- Responsive design
- Organized food categories
- Image presentation
- User-friendly navigation
- Modern CSS styling

## ✨ Features

- 🏠 Home / Welcome section
- 🍔 Burgers collection
- 🍟 Fries collection
- 🥗 Healthy food / Greens section
- 🍜 Noodles collection
- 🍰 Sweet desserts section
- 🧭 Navigation menu with section links
- 📱 Responsive layout for different screen sizes
- 🖼️ Food image gallery
- 🎨 Gradient backgrounds and styled headings
- ✨ Hover effects and image shadows
- 📄 Simple and clean footer

## 🛠️ Technologies Used

- **HTML5** – Used to structure the webpage and its content
- **CSS3** – Used for styling, layouts, responsiveness, gradients, shadows, and image presentation
